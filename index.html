GUIDE

이용 안내

역극을 기록하고 안전하게 보관하는 방법을 확인해 주세요.

01

역극 작성

캐릭터 이름과 인장 이미지를 등록한 뒤, 작성자를 선택하고 대사나 지문을 입력해 주세요. 추가한 게시물은 미리보기에서 수정·삭제할 수 있고, 드래그해서 순서를 바꿀 수 있어요.

02

자동 저장

작성 내용은 현재 사용 중인 브라우저의 저장 공간에 자동 저장됩니다. 브라우저 데이터나 사이트 저장 공간을 삭제하면 기록이 사라질 수 있으니 정기적으로 백업해 주세요.

03

백업과 복원

PNG는 보기 좋은 이미지로 보관할 때, JSON은 캐릭터·대사·메모를 다시 불러오고 싶을 때 사용해 주세요. 전체 프로젝트 백업은 모든 역극을 한 파일로 저장합니다.

04

기기 변경 시

자동 저장 내용은 다른 기기나 브라우저와 자동으로 동기화되지 않습니다. 기기를 옮길 때는 JSON 백업 파일을 만든 뒤 새 기기에서 ‘백업 불러오기’를 이용해 주세요.

05

이미지 저장

PNG 이미지 저장은 현재 미리보기 형식과 글꼴 설정을 반영합니다. 3:4 포스터 PNG는 흰 배경의 세로형 이미지로 저장됩니다. 긴 역극은 글자가 작아질 수 있으니 저장 결과를 확인해 주세요.

06

제작 배경

본디 가내 개인봇 자랑타래를 매번 편집하기 귀찮아서 개인적으로 사용하기 위해 만든 편집기입니다. 오류사항은 둥글게 말씀해주세요.

기록을 잃지 않도록 중요한 역극은 JSON으로도 보관해 주세요.
자동 저장은 현재 브라우저에 이루어집니다. 다른 기기에서 이어 쓰려면 JSON 백업을 보관해 주세요. 인장 이미지는 프로젝트 백업 파일에 포함됩니다.
